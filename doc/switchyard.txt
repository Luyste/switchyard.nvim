1. INTRODUCTION                                             *switchyard-intro*
                                                                  *switchyard*

switchyard moves the editor between git worktrees and project folders. One
floating window, the yard, lists the worktrees of your repo and the folders
around it; Enter moves the editor there.

Requirements: Neovim 0.12+ and git. Optional: sidekick.nvim
(|switchyard-sidekick|). See `:checkhealth switchyard`.

==============================================================================
2. SETUP                                                    *switchyard-setup*

>lua
    require("switchyard").setup({})
    vim.keymap.set("n", "<leader>y", function()
      require("switchyard").open_yard()
    end, { desc = "switchyard: the yard" })
<
switchyard sets no global keymaps.

==============================================================================
3. THE YARD                                                  *switchyard-yard*

A small float with two views; <Tab> switches between them.
                                                   *switchyard-yard-worktrees*
Worktrees view   The repo's worktrees. `@` marks the one the editor is in,
                 `*` one with uncommitted changes.
                                                     *switchyard-yard-folders*
Folders view     The folders around the repo. Repos are marked `git`, plain
                 folders end in `/`. Worktree folders are left out (they're
                 listed under their repo).

                                                        *switchyard-yard-keys*
Key (name)          Worktrees view              Folders view ~
<CR> (activate)     switch to the worktree      switch to the folder
l (enter)                                       look inside (a repo: its
                                                worktrees)
h (up)              the folders around the      one folder up
                    repo
n (new)             new worktree
D (remove)          remove worktree
y (copy_path)       copy the path               copy the path
1-9                 switch to row n             switch to row n
/ (filter)          filter                      filter
. (actions)         the row's actions           the row's actions
? (help)            every key of the view       every key of the view
<Tab>, <C-r>, q     other view, refresh, close

A new worktree for branch `b` goes next to the main one, as `<repo>.<b>`: an
existing (or remote) branch is checked out, a new one branches off the default
branch. Removing a worktree also deletes its branch when it's merged. The
current and the main worktree can't be removed.

                                                      *switchyard-yard-filter*
`/` opens a filter line above the list. Typing narrows the rows; <CR> switches
to the selected one, <Esc> clears the filter.

==============================================================================
4. SWITCHING                                            *switchyard-switching*

Switching never asks questions. With unsaved changes it refuses. Otherwise it
closes every window and file buffer of the old folder, stops the language
servers and `cd`s to the new folder.

==============================================================================
5. SIDEKICK.NVIM                                         *switchyard-sidekick*

With sidekick.nvim installed: when sidekick's agent window was open, it comes
back after a switch, showing the agent that runs in the new folder (if one
does). Turn it off with `integrations = { sidekick = false }`.

==============================================================================
6. FUNCTIONS                                                  *switchyard-api*

switchyard.setup({opts})                                  *switchyard.setup()*
    See |switchyard-config|.

switchyard.open_yard()                                *switchyard.open_yard()*
    Open the yard.

switchyard.switch({dir})                                 *switchyard.switch()*
    Move the editor to {dir}. Returns true when it moved.

==============================================================================
7. CONFIGURATION                                           *switchyard-config*

The defaults: >lua
    require("switchyard").setup({
      yard = {
        view = "worktrees", -- the view the yard opens in: "worktrees"
                            -- or "folders"
      },
      integrations = {
        sidekick = true,    -- used when installed
      },
      keys = {
        yard = {            -- inside the yard, see |switchyard-yard-keys|
          activate = "<CR>", enter = "l", up = "h", toggle_view = "<Tab>",
          filter = "/", refresh = "<C-r>", close = "q", actions = ".",
          help = "?", new = "n", remove = "D", copy_path = "y",
        },
      },
    })
<
==============================================================================
8. COMMANDS AND EVENTS                                   *switchyard-commands*
                                                                 *:Switchyard*
:Switchyard             Open the yard.
:Switchyard {folder}    Switch to {folder} (with folder completion).

                                                           *switchyard-events*
User SwitchyardSwitching    Before a switch closes the windows.
User SwitchyardSwitched     After a switch. For example, reopen a file tree: >lua
    vim.api.nvim_create_autocmd("User", {
      pattern = "SwitchyardSwitched",
      callback = function()
        require("nvim-tree.api").tree.open()
        vim.cmd.wincmd("p")
      end,
    })
<
Both carry `data = { from, to }`.
